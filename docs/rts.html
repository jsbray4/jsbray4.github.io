For this project, I designed an auto braking system for self-driving and smart-assistance cars. An analog potentiometer as input simulated a distance sensor that would be mounted on the front of the car. A servo simulated the brake. And a software-implemented estop was added for testing purposes. Lastly was added a heartbeat task to monitor the system status. This system was designed as a real-time system because it must interface with the physical world in real-time and meet specific deadlines to achieve its purpose.
